# 多板块重点股票设计

## 目标

把用户重点关注的股票放进对应板块，并补充少量当前确实值得持续跟踪的公司。所有上市公司统一进入行情、公告正文、正式评分、深度分析、走势图和每日验证流程。

## 分类

- 机器人
- 半导体
- 无人机
- 石油
- 电力
- 创新药
- 贵金属

分类不追求相同数量。建议股票必须有清楚、可持续验证的经营变化，不能为了覆盖角色、热门程度或短期涨幅凑名单。

## 重点标记

- 用户提供的股票标记为“你的重点”，在板块内优先显示。
- 系统建议的股票标记为“建议关注”。
- 原有机器人和半导体观察池不额外标记。

## 数据完整性

每只新增股票必须具备：

1. 当日行情和近 90 个交易日走势。
2. 交易所公告候选及正文。
3. Serenity 正式评分。
4. Serenity 深度分析。
5. 当日判断快照和后续每日验证。

如果正文或深度分析未完成，页面必须明确显示数据不足，不能用行情替代业务事实。

## 页面

顶部板块切换支持换行；卡片直接显示“你的重点”或“建议关注”。板块标题同时显示重点数量、建议数量、正式判断数量和深度分析数量。
