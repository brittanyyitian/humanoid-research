# 股票雷达参考图 UI 改造设计

## 目标

将股票雷达首页调整为参考图所示的高密度研究工作台：板块、搜索和排序位于顶部，左侧为可滚动股票列表，右侧为当前标的的完整分析。保留现有 Serenity 数据、判断逻辑、搜索、板块切换、个股选择、详情懒加载、每日复盘和证据链，不改变分析结构。

## 视觉方向

- 使用克制的黑白灰研究终端风格，减少装饰性大标题和大面积卡片底色。
- 桌面端采用约 420px 左栏与自适应右栏；右栏成为主要阅读区域。
- 股票卡片增加序号、价格和明确的涨跌，选中态使用深色描边。列表摘要没有完整逐日行情时不绘制趋势线，避免用稀疏数据制造看似真实的走势。
- 左栏采用高密度卡片，单张卡片控制在约 120–135px 高度，让桌面首屏能同时比较更多标的。
- 详情顶部将公司名、代码、业务角色、训练提示集中展示；关注理由改为横向提示条。
- 当前判断、评分、行情、技术趋势与依据保持原数据，但通过分隔线、留白和紧凑排版形成清楚的阅读顺序。
- 窄屏下退化为单列，股票列表横向滚动，详情继续完整展示。

## 组件与数据边界

- `StockRadarHero` 改为紧凑状态行，不再占用独立大卡片。
- `StockRadarToolbar` 保留原 props 与行为，仅调整 DOM 分组和可访问性。
- `StockRadarList` 只扩充纯展示字段，不新增业务计算。
- `StockRadarDashboard` 继续负责选择状态、详情懒加载和判断数据拼装。
- 只有具备完整时间序列的详情走势图才展示图形；列表不使用装饰性或推算式趋势线。

## 验收

- 板块切换、搜索、股票选择、详情懒加载、每日复盘和证据链接均可用。
- 快速切换股票不会出现旧详情。
- 桌面端视觉结构与参考图一致，窄屏没有横向溢出。
- 单元测试、数据检查、生产构建和浏览器控制台检查通过。
